# AGENTS.md

`laccd-class-search-cli` is an agent-native, read-only **Go 1.26** CLI (plus a companion MCP server) over the LACCD MyCollege guest class-search portal. It mirrors class sections into a local pure-Go SQLite store and layers on cross-college seat comparison, seat-watch, AB1111 course-number bridging, and schedule-conflict checks. The tree is **generated by [CLI Printing Press](https://github.com/mvanhorn/cli-printing-press)** — treat it as generated output, not hand-authored source.

## Setup
- Install Go 1.26.4+ (matches `go.mod` `toolchain go1.26.4`).
- `go mod download` to fetch deps (Cobra, `pelletier/go-toml`, `golang.org/x/net`, `modernc.org/sqlite` (pure Go — no CGO), `mark3labs/mcp-go`).
- No credentials or `.env` needed: the portal is the public guest search and the client warms up a PeopleSoft guest session automatically.

## Build & Run
```bash
make build           # -> bin/laccd-class-search-pp-cli
make build-mcp       # -> bin/laccd-class-search-pp-mcp
make build-all       # both binaries
make install         # go install ./cmd/laccd-class-search-pp-cli
```
Run against the live portal, then discover capabilities at runtime instead of trusting a stale command list:
```bash
bin/laccd-class-search-pp-cli doctor --json          # config + connectivity
bin/laccd-class-search-pp-cli agent-context --pretty # machine-readable overview
bin/laccd-class-search-pp-cli which "<capability>" --json
bin/laccd-class-search-pp-cli <command> --help
```
Add `--agent` for JSON + compact + no-color + non-interactive output. Prefer `--dry-run` before any unfamiliar command.

## Testing
```bash
make test            # go test ./...
make lint            # golangci-lint run  (config in .golangci.yml)
```
Tests live beside their code as `*_test.go` (e.g. `internal/cli/*_test.go`, `internal/laccd/parse_test.go`, `internal/cliutil/*_test.go`) and rely on in-repo fixtures — no network. Before a change is done: `go test ./...` and `golangci-lint run` must both pass, and `bin/laccd-class-search-pp-cli doctor` should still succeed.

## Code Style
- Standard Go: `gofmt`/`goimports`, package-scoped `internal/` layout, one command per file under `internal/cli/`.
- Keep the agent contract intact: every command stays non-interactive and supports `--json`, `--select`, `--dry-run`, and `--agent`; write errors to stderr and honor the exit-code map (`0` ok, `2` usage, `3` not found, `5` API, `7` rate-limited, `10` config).
- This CLI is read-only — do not add commands that mutate remote state.
- **Generated tree:** fix systemic problems upstream in Printing Press first, keep local edits narrow, and record any intentional local change under `.printing-press-patches/` so a reprint carries the intent forward instead of dropping it.

## Commit & PR Conventions
- Git repo: `github.com/johnnyrobot/laccd-class-search-cli`, default branch `main`.
- Do **not** commit built binaries, `*.db*` mirrors, `*.mcpb` bundles, or `/.printing-press*.json` (all in `.gitignore`).
- Never hand-bump `var version = ...` or `CHANGELOG.md` for releases — the `mvanhorn/printing-press-library` publish workflow assigns the `YYYY.M.N` version. Keep PRs scoped and explain why any generated-tree patch belongs here.

## Security & Data
- No secrets, tokens, or API keys anywhere in this repo — nothing to leak.
- Only public LACCD class-search data flows through it; the local SQLite mirror holds public schedule data and is gitignored.
- Network egress is limited to the public LACCD portal; be mindful of rate limits (see `internal/cliutil/ratelimit.go`) and let the client re-establish the guest session on `session expired`.
